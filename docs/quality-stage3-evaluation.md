## Проверки и остающаяся приёмка

Финальный `ops/check-quality.ps1 -Fix`: **3199 passed, 120 skipped**, 220,20 с;
**405/405 frontend tests**, Ruff check/format, pip check и git diff --check — успешно.
Пропускаемые проверки с реальными PostgreSQL/Qdrant выполняются штатным Linux gate,
а не объявляются успешными mocks. Лог: `.codex-test-temp/stage3-quality-release.log`.
Новый пакет unit/regression и HTTP-проверка 31 страницы укладываются в две минуты без GPU.
Отдельная финальная прямая модельная проба страницы 26 — 18,88 с, один запрос/2062 токена;
13/20 строк системно привязаны, семь сохранены без придуманных связей.

Полный повторный анализ через n8n не выполнен: исходные API-job недоступны, SSH-ключ отклонён,
а рабочее развёртывание выполняет пользователь. Новый серверный JSON, полный набор источников,
реальные отметки disposition и инженерная разметка нужны для заполнения последней колонки матрицы.
Точность геометрии страницы 26 и исходная жалоба на мышиный resize остаются пунктами ручной приёмки.
