# Выгрузка фиксированного набора Experience

Документ описывает переносимый набор для подготовки эксперимента дообучения.
Выгрузка не запускает обучение, не создаёт веса и не переключает рабочую VLM.

## Отбор и фиксация

Инженер выбирает строки чекбоксами и создаёт набор дообучения. Сервер проверяет
актуальность источников, наличие изображений и однозначность разметки, сообщает
причины исключения и фиксирует пригодные редакции в одной версии. Все примеры
одной версии относятся к одному разделу нормативного документа.

Новые наборы сохраняют исходный и текущий тексты, исходное и текущее нормативное
основание, решение инженера, назначение положительного или отрицательного
примера, SHA документа, происхождение и отдельные виды геометрии:

- `proposed_regions` — первоначальные области VLM вместе с происхождением;
- `issue_regions` — области, по которым подготовлены изображения;
- `display_regions` — отдельная инженерная правка отображаемых областей;
- `callout_box` — размещение карточки замечания;
- `area_source` — источник областей, использованных для примера.

Координаты нормализованы в диапазоне 0–1000 по соответствующему листу.
Для Bad первоначальная область и изменённая инженером область не подменяют
друг друга. Для неоднозначного Edited + Rejected набор создаётся только после
разметки причины отказа и выбора отрицательного текста: исходного, исправленного
либо обоих.

## HTTP-контракт

`GET /api/v1/experience-versions/{version_id}/dataset` возвращает ZIP выбранной
версии. Gateway до выдачи проверяет доступ ко всем заданиям, записанным в её
фиксированном составе. Внутренний маршрут
`GET /internal/v1/experience-versions/{version_id}/dataset` доступен только
доверенному каналу Review; индексный служебный ключ не даёт доступа к архиву.

В архиве находятся:

| Файл | Содержание |
| --- | --- |
| `manifest.json` | Идентификатор версии, название, базовый контракт модели, раздел, автор, редакция, SHA состава и JSONL, перечень PNG с SHA и размерами |
| `examples.jsonl` | По одной строке UTF-8 на зафиксированную редакцию, полные тексты, разметка и ссылки на изображения |
| `crops/<example_id>/<ordinal>.png` | Все изображения областей примера; целые листы PDF не включаются |

`base_model_contract` содержит выбранный логический контракт модели. Для
фактического обучения позднее требуется отдельно зафиксировать физическую модель,
её редакцию, конфигурацию адаптера и обучающего процесса. Этот архив не выдаётся
за готовый формат конкретного тренера.

## Целостность и воспроизводимость

Экспорт читает тексты и разметку из `ArtifactVersion.members`, изображения — из
неизменяемого PNG-хранилища по SHA. Текущий каталог не используется для замены
исторических данных. Последующая правка или удаление примера не меняет набор.
Перед выдачей проверяются SHA состава версии, PNG и размеры изображений; повторное
чтение версии обнаруживает конкурентное переименование, изменение или удаление.

Повторная выгрузка неизменённой версии формирует тот же ZIP побайтно. Ограничения:
до 1000 примеров и 100 МБ суммарного содержимого. Повреждённый либо недоступный PNG
не заменяется пустой картинкой; весь запрос завершается ошибкой. Удалённые версии
не выдаются через пользовательский API.

Старые версии и векторные версии без сохранённой геометрии экспортируются с
`geometry_status: not_recorded_in_version`. В manifest записывается
`missing_geometry_count`. Координаты не восстанавливаются из изменившегося
каталога. Изображения и остальные зафиксированные сведения сохраняются.

Выгрузка исторического набора сама по себе не подтверждает его пригодность для
обучения после последующих изменений источников. Проверка качества и независимый
проверочный набор остаются отдельными условиями допуска экспериментальных весов.
