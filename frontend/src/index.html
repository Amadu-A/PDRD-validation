Проверка проектной и рабочей документации

Загрузите PDF, DWG/DXF или PDF вместе с соответствующим CAD-файлом. Анализ выполняется асинхронно через API Gateway.

Для PDF-only можно анализировать одну или несколько физических страниц документа.

CAD-only считается одним анализируемым листом.
