# Сертификаты окружения

Каталог монтируется только в `auth-service` по пути
`/run/pdrd-auth-certificates` в режиме read-only.

Перед включением корпоративного входа администратор сервера помещает сюда файл
`ad-ca.pem` с публичной доверенной цепочкой CA, которая выдала действующий
LDAPS-сертификат контроллера `WIN-1L5FI1SGC9J.itcneoterm.local`.

Файл сертификата не коммитится. Закрытый ключ контроллера PDRD не нужен и не
должен копироваться в этот каталог.
